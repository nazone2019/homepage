# NAZONE 草案（画像ベース）

`homepage_hp.webp` などモック画像を土台に、完成図相当の動きとページ遷移を足した確認用サイトです。

## 開き方

`draft/index.html` を開くか、`/draft/` にアクセスしてください。

## ページ

- `/draft/` … ホーム
- `/draft/about.html` … About
- `/draft/works.html` … Works
- `/draft/goods.html` … Goods
- `/draft/contact.html` … Contact（SSGform 送信対応）

## 動き・操作

- ホーム: 「ココロざす」「志す」フェード、SCROLL、カルーセル
- ハンバーガーはモバイルのみ（完成図の位置）。PCは0001型サイドメニュー
- カスタムカーソル（`homepage_point.webp` 由来）
- Works / Goods はカード一覧＋フィルタ（すべて / ルーム型 など）
- LINE謎・WEB謎は Goods（Web）に分類
- About のメンバーカードはホットスポットで遷移
